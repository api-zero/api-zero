# React Integration

El paquete `@api-zero/react` proporciona una integración idiomática, declarativa y type-safe con React 18 y React 19.

## Instalación

```bash
npm install @api-zero/core @api-zero/react
# o
pnpm add @api-zero/core @api-zero/react
```

## Características

- ⚛️ **Compatible con React 18 y 19**: Soporta concurrent features y StrictMode sin memory leaks.
- 🛡️ **ApiProvider Estable**: Acepta configuración o una instancia existente de cliente, asegurando estabilidad referencial.
- 📡 **`useRequest`**: Hook declarativo para data fetching con auto-abort en desmontaje o cambio de parámetros.
- ⚡️ **`useMutation`**: Hook de mutaciones con soporte síncrono y asíncrono (`mutate` / `mutateAsync`), y callbacks de ciclo de vida (`onSuccess`, `onError`, `onSettled`).
- 🎯 **Integración con Zod**: Totalmente interoperable con `@api-zero/zod` para validación e inferencia de tipos de esquemas.
