# useRequest

`useRequest` es el hook principal para realizar consultas (`GET`) de datos en React. Maneja automáticamente los estados de carga, error y éxito, e implementa cancelación reactiva mediante `AbortController` al desmontar el componente o al cambiar los query parameters.

## Importación

```tsx
import { useRequest } from '@api-zero/react';
```

## Firma

```typescript
function useRequest<TData = unknown, TParams = Record<string, unknown>>(
  endpoint: string,
  options?: UseRequestOptions<TData, TParams>
): UseRequestResult<TData>
```

### Opciones (`UseRequestOptions`)

```typescript
interface UseRequestOptions<TData, TParams> extends RequestOptions<TData, unknown, TParams> {
  /** Si está en false, no ejecuta la petición automáticamente al montar (default: true) */
  enabled?: boolean;
  /** Datos iniciales antes de la primera respuesta */
  initialData?: TData;
  /** Parámetros de query serializados automáticamente */
  params?: TParams;
  /** Callback ejecutado al recibir una respuesta exitosa */
  onSuccess?: (data: TData) => void;
  /** Callback ejecutado ante un error */
  onError?: (error: ApiError) => void;
}
```

### Retorno (`UseRequestResult`)

```typescript
interface UseRequestResult<TData> {
  data: TData | undefined;
  loading: boolean;
  error: ApiError | null;
  isSuccess: boolean;
  isError: boolean;
  isIdle: boolean;
  refetch: () => Promise<TData | undefined>;
  abort: () => void;
}
```

## Ejemplos de Uso

### 1. Petición Básica Tipada

```tsx
import { useRequest } from '@api-zero/react';

interface User {
  id: number;
  name: string;
  email: string;
}

export function UserProfile({ userId }: { userId: number }) {
  const { data: user, loading, error, refetch } = useRequest<User>(`/users/${userId}`);

  if (loading) return <div>Cargando perfil...</div>;
  if (error) return <div>Error al cargar: {error.message}</div>;
  if (!user) return null;

  return (
    <div>
      <h2>{user.name}</h2>
      <p>{user.email}</p>
      <button onClick={() => refetch()}>Actualizar</button>
    </div>
  );
}
```

### 2. Paginación Reactiva

Cuando cambian las propiedades en `params`, `useRequest` aborta cualquier petición en curso y lanza automáticamente la nueva:

```tsx
import { useState } from 'react';
import { useRequest } from '@api-zero/react';

export function PaginatedUsers() {
  const [page, setPage] = useState(1);

  const { data, loading } = useRequest<User[]>('/users', {
    params: { page, limit: 10 },
  });

  return (
    <div>
      {loading && <span>Cargando página {page}...</span>}
      <ul>
        {data?.map((u) => (
          <li key={u.id}>{u.name}</li>
        ))}
      </ul>
      <button onClick={() => setPage((p) => p + 1)}>Siguiente Página</button>
    </div>
  );
}
```

### 3. Validación de Esquemas con `@api-zero/zod`

Pasa `zodResponse(schema)` directamente a las opciones de `useRequest`:

```tsx
import { useRequest } from '@api-zero/react';
import { zodResponse } from '@api-zero/zod';
import { z } from 'zod';

const ProductSchema = z.object({
  id: z.number(),
  title: z.string(),
  price: z.number(),
  createdAt: z.string().transform((str) => new Date(str)),
});

export function ProductDetails({ id }: { id: number }) {
  // 'data' queda automáticamente tipado e inferido como:
  // { id: number; title: string; price: number; createdAt: Date }
  const { data: product, loading } = useRequest(
    `/products/${id}`,
    zodResponse(ProductSchema)
  );

  if (loading) return <div>Cargando producto...</div>;
  return <div>{product?.title} - ${product?.price}</div>;
}
```
