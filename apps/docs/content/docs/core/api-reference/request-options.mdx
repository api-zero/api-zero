The last argument of every verb. Each option overrides the client's value for
this request only — setting `timeout` here does not disturb the headers or the
retry policy configured on the client.

<auto-type-table path="../../../../../../packages/core/src/types.ts" name="RequestOptions" />

<Callout type="info">
  `timeout: 0` really does disable the timeout. The value is resolved with `??`
  rather than `||`, so a deliberate zero is not mistaken for "unset" — a
  distinction many clients get wrong.
</Callout>
