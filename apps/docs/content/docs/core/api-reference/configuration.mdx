Passed to `createClient`, and applied to every request the client makes.
Anything here can be overridden for a single call through
[`RequestOptions`](/docs/core/api-reference/request-options).

## Changing it later

<include meta='title="lib/api.ts"'>../../../../../../examples/src/client-config.ts</include>

`setConfig` merges: keys you do not mention keep their value.

<Callout type="warn">
  On a server, a module-level client is shared by every request the process
  handles. Anything request-scoped — an auth token above all — must not be set
  on it, or one user's credentials leak into another user's request. Create a
  client per request instead.
</Callout>
