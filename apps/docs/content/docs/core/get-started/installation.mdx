## Requirements

- **Node.js 22 or newer.** api-zero uses native `fetch`. Node 18 and 20 reached
  end of life and are not supported — see
  [ADR-002](https://github.com/api-zero/api-zero/blob/main/docs/adr/002-supported-node-versions.md).
- Modern browsers and Edge runtimes (Cloudflare Workers, Vercel Edge) work too.
  Edge is Fetch-only: upload and download progress need XHR, which exists only
  in browsers.

## Setting it up

### Create the client once

Export a single configured instance and import it everywhere. Creating a client
per call throws away the headers, interceptors and retry policy you configured.

<include meta='title="lib/api.ts"'>../../../../../../examples/src/create-client.ts</include>

In React, hand that instance to `ApiProvider` instead — see
[the React package](/docs/react).

<Callout type="info">
  Both ESM and CommonJS are published, and the type declarations resolve under
  `node16` module resolution, the strictest consumer setup. CI installs the
  packed tarballs into a clean project on every commit to keep that true.
</Callout>
