Every project starts the same way. You add `fetch`, then you write a wrapper to
hold the base URL. Then a place to stash the auth token. Then an interceptor for
401s. Then `.get` and `.post` helpers so callers stop repeating themselves. That
file is called `api.ts` or `useApi.ts`, it is subtly different in every project,
and nobody ever tests it.

**api-zero is that file, written once and maintained for you.**

## What it does

- **Transport you can rely on** — timeouts and cancellation that compose, retries
  that refuse to repeat an unsafe request, and errors that tell you what
  happened instead of `TypeError: Failed to fetch`.
- **Contracts checked at runtime** — optional Zod integration so the shape you
  typed is the shape you actually received.
- **One configured client, everywhere** — auth, headers and interceptors defined
  once and reachable from any module or component.

### What it deliberately does not do

api-zero is **not** a data-fetching library. It has no cache, no deduplication,
no invalidation and no `useQuery` equivalent. Those belong to
[TanStack Query](https://tanstack.com/query) or [SWR](https://swr.vercel.app),
which solve them far better than a transport layer should try to.

api-zero sits **underneath** them. Pairing the two is the intended setup, not a
workaround — see [the React package](/docs/react).

If you only ever call one endpoint, plain `fetch` is the right answer and you do
not need this.

## The packages

### Size

Measured from the published ESM bundles, gzipped. CI enforces a ceiling on each
number so this table cannot quietly stop being true.

| Package | Gzipped | Purpose |
| ------- | ------: | ------- |
| `@api-zero/core` | ~6.0 kB | Client, transport, errors, interceptors, retries |
| `@api-zero/react` | ~0.7 kB | `ApiProvider` and `useApi` |
| `@api-zero/zod` | ~1.2 kB | Schema-validated requests and responses |

Only `@api-zero/core` is required. The other two are opt-in.

They are split by dependency direction, not by size: `core` depends on nothing,
`react` peer-depends on React, `zod` peer-depends on Zod. You install only what
your runtime already has.
