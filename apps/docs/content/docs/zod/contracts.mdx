# Contratos de API con `defineContract`

`defineContract` permite declarar contratos de API centralizados que especifican la ruta, el método HTTP, y los esquemas de Zod para parámetros, cuerpo y respuesta.

## Definición de Contratos

```typescript title="api/contracts/users.ts"
import { defineContract } from '@api-zero/zod';
import { z } from 'zod';

export const getUserContract = defineContract({
  method: 'GET',
  path: '/users/:id',
  response: z.object({
    id: z.number(),
    name: z.string(),
    email: z.string().email(),
  }),
});

export const createUserContract = defineContract({
  method: 'POST',
  path: '/users',
  body: z.object({
    name: z.string().min(2),
    email: z.string().email(),
  }),
  response: z.object({
    id: z.number(),
    name: z.string(),
    email: z.string(),
    createdAt: z.string(),
  }),
});
```

---

## Ejecución de Contratos

Los contratos proporcionan un método `.execute(client, args)` fuertemente tipado:

```typescript
import { createClient } from '@api-zero/core';
import { createUserContract } from './api/contracts/users';

const client = createClient({ baseURL: 'https://api.example.com' });

// Ejecución con validación automática de body y tipado de respuesta:
const newUser = await createUserContract.execute(client, {
  body: {
    name: 'Alice',
    email: 'alice@example.com',
  },
});

console.log(newUser.id); // number
```
