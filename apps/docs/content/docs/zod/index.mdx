# Zod Integration

El paquete `@api-zero/zod` añade soporte de primer nivel para validación de esquemas de Zod en `api-zero`, transformando errores en instancias estructuradas de `ZodValidationError` y proporcionando inferencia de tipos estáticos (`z.infer`).

## Instalación

```bash
npm install @api-zero/core @api-zero/zod zod
# o
pnpm add @api-zero/core @api-zero/zod zod
```

## Características

- 🛡️ **Validación de Respuestas y Peticiones**: Valida `response`, `body` y `params` con schemas de Zod.
- ⚡️ **`ZodValidationError`**: Extiende de `ApiError` (`isValidationError: true`) con `.issues`, `.flatten()` y `.format()`.
- 🔄 **Async & Coercion**: Soporta esquemas asíncronos y transformaciones de Zod (`safeParseAsync`).
- 🪄 **`ZodApiClient`**: Cliente tipado con métodos directos (`api.get('/users', UserSchema)`).
- 📜 **`defineContract`**: Definición de contratos de API fuertemente tipados y reutilizables.
