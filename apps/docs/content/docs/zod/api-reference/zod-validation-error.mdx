Extends [`ApiError`](/docs/core/api-reference/api-error), so everything that
already handles errors handles this one.

Everything inherited from `ApiError` also applies: `request`, `cause`,
`attempt`, `toJSON()` and the `is*()` helpers.

<Callout type="info">
  `isRetryable()` returns `false` for a validation error. A payload that failed
  the schema fails identically on the next attempt.
</Callout>
